## 必要なアーキテクチャ変更

現行は AliExpress 専用に彫り込まれている（`a.search-card-item` のセレクタ、mtop の API 解決、`blockedStores` という storeId 前提の storage）。汎用化には **サイトアダプタ** を1枚挟む。

サイトごとに定義するのは3つだけ:
1. どの URL で動くか（`matches`）
2. カード要素は何か（セレクタ）
3. 発信元をどう取るか（**DOM 直読み** か **非同期解決＋キャッシュ** か）

非表示の当て方（プレースホルダー / 詰めて消す）、キャッシュ、MutationObserver 追従、ブロックリストの storage は共通化する。storage のキーは `blockedStores` から、サイト種別を含む形へ移行が要る（既存ユーザーのデータ移行を伴うので、v2.0 で慎重に扱う）。
