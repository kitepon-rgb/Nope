# Nope — 見たくないもの見せません

指定した発信元やキーワードのコンテンツを、閲覧中の Web ページから非表示にする Chrome 拡張機能（Manifest V3）です。ショップ・出品者・チャンネル・出版社をサイト別にブロックでき、Yahoo ニュースと Yahoo! JAPAN ではキーワードでも絞り込めます。

## 機能

- **発信元をブロック**: 対応ページのショップ・出品者・チャンネル・出版社を登録すると、その発信元のカードを自動的に隠します。AliExpress の商品ページでは「このストアをブロック」ボタンから登録できます。
- **キーワードをブロック**: Yahoo ニュースと Yahoo! JAPAN の記事タイトルを、登録したキーワードの部分一致で非表示にできます。
- **その場で反映**: ブロックリストを変更すると、ページを再読み込みせずに再判定します。
- **表示方法を選択**: ブロックしたカードをプレースホルダーへ置き換えるか、完全に非表示にして詰めるかを選べます。
- **ポップアップで管理**: ツールバーのアイコンから、サイト別のブロック対象とキーワードの確認・追加・解除、表示方法の切替、解決キャッシュの削除ができます。

## 導入手順

現時点では Chrome ウェブストアには未公開のため、開発者モードでの読み込み（Load unpacked）で導入します。ストア公開後はここにストアのリンクを追記します。

1. このリポジトリをダウンロードまたは `git clone` する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を選び、リポジトリのルートフォルダ（`manifest.json` があるフォルダ）を指定する
5. 上記の対応ページを開き、ツールバーの Nope アイコンから設定する

## プライバシー

- **開発者や第三者が運営するサーバーへの送信はありません。** 発信元の識別に追加通信が必要な場合だけ、閲覧中のサービス自身へ公開の商品ID・オークションIDを問い合わせます（AliExpress・ヤフオク・Amazon.co.jp）。
- **利用状況の収集・送信は行いません。** アクセス解析やトラッキングの類は組み込んでいません。
- **データの保存先は Chrome の `chrome.storage` のみです。**
  - ブロックした発信元・キーワードと表示モードは `chrome.storage.sync` に保存され、ログイン中の Google アカウントで同期されます。
  - 商品・オークションIDから発信元を解決した結果は、通信回数を減らすため `chrome.storage.local` に保存されます（端末内のみ、同期されません）。
- API 権限は `storage` のみです。対応ページへ機能を注入するため、各サイトを `content_scripts[].matches` に宣言しています。

詳細は [プライバシーポリシー](docs/store/privacy.md) をご覧ください。

## 技術メモ

- サイト固有の DOM と発信元解決を `src/adapters/` に分離し、非表示・再判定・キャッシュを共通エンジンで処理します。
- AliExpress のストアID解決には内部API（`mtop.aliexpress.pdp.pc.query`、署名付きJSONP）、ヤフオクと Amazon.co.jp では同一サイトの商品詳細ページを使います。
- 非同期解決は同時2件・間隔300msに制限し、結果をサイト別のキーで端末内へキャッシュします。
- 無限スクロールや SPA 遷移によるカードの増減には `MutationObserver` で追従します。
